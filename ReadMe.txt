Voila un projet implémentant yt-dlp.
Frontend en HTML, CSS et JavaScript et backen en python. 

Il est possible de copier des liens Youtube dans un fichier texte et d'importer ce fichier pour télécharger en file les vidéos.
Il est possible de choisir le format d'exportation et la qualité. 

Une implémentation des Web Playerr (Apple Music et Spotify) est en cours.
